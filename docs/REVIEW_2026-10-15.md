# Desktop review — 2026-10-15

The review covered the Desktop adapter, ownership and backup handling, recent HelixSR removal, launcher dispatch, queued jobs and shared profiles. The original OptiDX script and OptiScaler fork were left untouched. A source backup was created before changes.

| Finding | Result after the fix |
| --- | --- |
| Mapped Wine drives and dot-relative HelixSR paths did not match generated Z: paths | Resolve configured Wine drive mappings and normalized relative paths before reconnecting direct lossy FSR |
| Failed installation could leave a stale baseline; failed uninstall could consume its baseline pointer | Restore baseline metadata together with installation snapshots |
| HelixSR removal saved component choices before final inspection and could overwrite concurrent choices | Commit after inspection using fresh saved choices; preserve unrelated component changes |
| One failed recovery step skipped the remaining game-file recovery | Attempt each location independently and name any remaining recovery errors |
| Queued jobs retained mutable Game objects | Copy the game record when queued |
| Shader picker and vkBasalt callback used the currently selected game | Bind results and subsequent writes to the originating game |
| Shared profiles copied another game's plugin folders, environment and package choice | Preserve game-specific fields during batch application |
| Native Heroic could receive a game discovered through Flatpak | Record launcher ownership during discovery and dispatch to the matching installation |
| ARM64 DLLs passed a 64-bit-only check; incomplete PE headers could retain architecture flags | Validate machine type and header layout for downloaded DLLs/addons |
| Capitalization differences could produce competing files under Wine | Reject ambiguous existing and proposed path spellings before deployment |
| Valid JSON arrays/objects could become unusable environment values | Validate environment overrides when saving/exporting and encode booleans as 1/0 |
| Custom display names were excluded from search | Search original titles and saved display names |
| Archive duplicate checks repeatedly scanned preceding entries | Use a set; cache existing directory spellings per deployment |

## Validation and limits

122 automated checks pass against temporary game folders. Targeted regressions cover the failure cases above, including a simulated late uninstall failure and a failed external recovery. UI dispatch checks avoid starting real games. Distribution verification uses the bundled interpreter and an offscreen AppImage startup.

This does not establish live-download availability or gameplay compatibility for every upstream package, GPU, runner or game. ReLimiter's repeated MMCSS warning is an external addon issue; this review does not modify that binary. Previously cached Heroic entries need a library refresh to record launcher ownership.
